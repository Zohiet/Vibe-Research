# Goal Backlog

**这是一本流水账，不是真相源。** 它只记「有什么事该做 / 做到哪了」各一行；
每条具体做什么、怎么验收，**唯一真相源是 `docs/goals/VR-GOAL-XXX_*.md`**。

用法：想做的记一行；开成 Goal 了补上编号；做完了划掉，别删——划掉的行是「这条已经落地」
的最短说明。**不要把 Goal 的内容抄进来**，一抄就有两处会漂移。
