# 一、业务验收（正文）

## 做成了什么

VR-GOAL-023 让自选股页能**回头看**（最新一期财报什么时候发的）。本 Goal 补上**往前看**：
每只股票多一格「下次财报」，显示交易所预约披露日与还有几天，5 天内按剩余天数分三档上色，
越近越显眼。

三件事值得单独说：

**这一列一年约有 5 个月对全市场是空的，而这被当成设计前提而非缺陷处理。** 预约披露表在
报告期末前后才入库（实测五期的入库时间），上一期披露完到下一期排表之间是空窗。所以
「查不到下次」显示的是**「待公布」**，与「接口挂了」的 `—` 分开——为此 `/api/next-earnings`
**刻意不沿用** `/api/earnings`「取不到就省掉键」的约定，而是给每个请求的 code 都返回一个键。

**逾期未披露的会自己浮出来，且不需要特例代码。** 取数规则是「未披露中预约日最早的一条，
含已过期」。`*ST萃华` 的一季报预约 04-29 至今未披露，按这条规则它显示「已过 101 天」——
比显示它的半年报预约日更值得知道。

**顺带修掉了 023 留下的一张空头承诺**：目标价表头那个感叹号只有 `aria-label="目标价说明"`、
**没有 `title`**——悬停什么都不出来，读屏念出来也不含任何解释。

## 与 Plan 的偏差

**① 三档目标对比度从等差改成等比（5.5/7.5/10.0 → 5.0/8.0/12.8）。**
实现时才算出来：两个 token 的互相对比度**恒等于**它们各自对卡片对比度的**比值**，
所以 Plan 里那组等差值换算成互相对比度只有 **1.35 / 1.32**，按本仓库既有的
「相邻档 ≥1.5」口径是**压平的**。改成公比 1.6 的等比数列后实测 1.62 / 1.57。
**Plan 在这一点上写错了，不是实现走样。**

**② `/api/next-earnings` 改为「每个请求的 code 都返回一个键」。**
Plan 照抄了 023 的「取不到的 code 不出现在返回里」，但那样**「待公布」和「接口挂了」
在前端就分不开了**，而验收项 2 明确要求可区分。改为值 `null` 表示没有下次预约。

**③ 截图从 5 张收敛成 3 张。** 桩数据本来就把六种状态放在同一屏，前四张字节数几乎相同
——那是同一屏截了四次。合并成「六种状态同屏」一张，另加亮色一张（证明色阶方向相反）
与降级一张。

**④ Plan 没预料到的：变红实验④ 一条都没红。**
把取数改成「只取未过期的」后，`*ST萃华` 那条逾期记录直接消失，**却没有任何测试变红**——
「含已过期」这条拷打定下的规则原先只有 `-m live` 覆盖，而 E2E 是打桩的。
补了 `batch_next_earnings` 的三条 mock 测试后重跑，这次正确变红。
**这是本 Goal 最值钱的一条产出：变红实验的价值不在于确认护栏有效，而在于发现护栏不存在。**

## 遗留与后续

- **阈值 5 天与三档分界（5-4 / 3-2 / 今明）都是拍的**，负责人明确说「先取 5 天」。
  实测 68.8% 的公司挤在 8 月最后一周，**财报季末这一列会大面积上色**——那几天它们确实
  全都临近，高亮没说谎，但观感如何要跑完一个财报季才知道。改阈值是改一个具名常量。
- **`published` 字段恒为 false**（取数时已按 `IS_PUBLISH="0"` 过滤），UI 不据此分支。
  留着是为了记录取数口径，但它确实是个不承重的字段。

### 防假绿的两条硬断言

主题相关的用例里加了两条，因为「切主题没生效」会让两个主题读到同一组颜色而**双双变绿**
（VR-GOAL-021 的 placeholder 正是这么假绿的：算出来 4.63、实测亮色只有 2.32）：

1. 断言 `<html>` 上确实有对应主题的 class；
2. 断言色阶**方向**——暗色越紧迫越亮、亮色越紧迫越深。一套值套两个主题会让其中一个反掉，
   而那不会有任何编译或运行时报错。

# 三、复核要点

**没达成 / 部分达成的验收项**

**与 Plan 的偏差**

- **Plan 的三档对比度目标值算错了**（等差 5.5/7.5/10.0 → 互相只有 1.35，压平）。
  实现时改成等比 5.0/8.0/12.8。这是 Plan 的错，不是实现走样，但你确认时看到的是那组错的数。
- **`/api/next-earnings` 的返回约定与 Plan 不同**：Plan 照抄 023 的「省掉取不到的键」，
  那样「待公布」和「接口挂了」在前端分不开。改为每个 code 都返回键、值 `null` 表示没有下次。
- 截图 5 张收敛成 3 张（前四张是同一屏截了四次）。

**新引入的风险**

- ⚠️ **变红实验④ 暴露过一个测试盲区**：「取未披露中最早的一条、**含已过期**」这条规则
  当时没有任何离线测试覆盖，改掉它 CI 全绿。已补三条 mock 测试并重跑确认变红。
  **同类风险可能还在别处**——凡是「取数规则」而非「纯计算」的逻辑，本仓库目前普遍只有
  `-m live` 覆盖。
- **阈值 5 天与三档分界是拍的**，且实测 68.8% 的公司挤在 8 月最后一周——**财报季末
  这一列会大面积上色**。那几天它们确实全都临近，高亮没说谎，但观感要跑完一个财报季才知道。
- **这一列一年约 5 个月整片是「待公布」**（决策 1 已知情裁决）。截图用打桩数据，
  不受当天日历影响；但你在 9 月初打开真实页面时看到的会是一整列「待公布」。
- `published` 字段恒为 `false`，是个不承重的字段。
