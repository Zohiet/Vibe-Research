# 一、业务验收（正文）

## 做成了什么

自选股页多了一列**前向 PE**（`26E 19 · 44家`），单独成组「一致预期」。它回答的是
「以今天的价格买，对应机构预期的多少倍盈利」——和已有的 PE(TTM) 是同一类指标，
只把分母从已实现盈利换成机构一致预期。

**但这个 Goal 交付的第二样东西可能更重要：表格宽度护栏。** 这是第 5 个往同一张表
加列的 Goal，表已经 22 列。护栏断言表格内容宽度不超过容器可用宽度——
**它红了不代表实现坏了，代表这张表满了**，那时正确的动作是先回答「砍哪列」，
而不是顺手再加宽一次容器。

拷打阶段砍掉了原计划的另一半（评级变动），并在中途换掉了数据源——理由都在下面。

## 与 Plan 的偏差

**① 容器加宽被撤回——决策 1 的前提是错的。**
Plan 说「21 列约 1670px，容器 1800px 只剩 130px，前向 PE 一格约需 150px，不加宽就装不下」。
**那个 1670px 是从 VR-GOAL-023 的估算外推的，而我把它当成了实测。**
实测：22 列表格只有 **1574px**；且 1800 与 2000 两个值下测得完全相同
（1920 viewport 下容器被视口限制在 1616px，`max-w` 根本没起作用）。
**加宽是不必要的，已改回 1800px。** 护栏那一半保留——它现在是真实测量而不是估算。

**② 过期规则在实现时改过。**
Plan 写的是「第一个 `E` 年度早于当前年份即过期」，**会在每年 1~4 月误报**：
A 股年报最迟次年 4 月底披露完，所以 2027 年 1 月时 2026 年的 EPS 合法地仍是预测。
改为对齐披露日历——早于当年即过期，但 1~4 月容忍上一年度。

**③ 后端 `forward_pe` 已删除——Plan 里那个「两份实现」的判断是错的。**
Plan 承认这是「最不舒服的一处」，并说「用同一组数值在 pytest 与 E2E 各断言一次盯住漂移」。
验收时 `grep` 核查调用方，发现**后端那份在生产路径上从不执行**（前向 PE 必须在前端算，
因为后端拿不到现价）。而**测 Python 那份证明不了 TypeScript 那份**，后者才是真正跑的
——那不是双保险，是假保证，且正是「从不执行的代码就是 bug 藏身处」的标准形态。
已删掉它与 4 条单测，边界改由 E2E 用具体数值断言。

**④ 表头说明与排序按钮无法共存（E2E 抓到的实现错）。**
表头渲染的三分支里 `col.sort` 在最前面，**可排序列根本到不了挂说明的那一支**。
目标价没有排序才碰得到。已改成两者可共存，并抽出 `HINT` 表。

**⑤ 截图从 2 张并成 1 张。** 桩数据把五种状态放在同一屏，两张字节数只差 3。
**这已经是第三次踩同一个坑**（023 / 024 各一次），已在 spec 注释里留痕。

## 遗留与后续

- **一致预期在项目里现在有两个来源**：自选股页用东财 `RPT_WEB_RESPREDICT`，
  个股页仍走 akshare 同花顺（`pe_26e`）。实测两者几乎一致（19.0/18.7/6.5 vs 19.1/18.7/6.5），
  但**不是同一个数**。本轮不动个股页。
- **`RPT_WEB_RESPREDICT` 的目标价与评级分布没有用**，尽管它都提供了——
  那张表没有时间窗口，陈旧值原样堆着。见下方实测。

# 三、复核要点

**没达成的验收项**：无，9 条全部达成。

**与 Plan 的偏差（三条都是我自己的判断被实测推翻）**

1. **容器加宽被撤回。** 你批准 2000px 时看到的「不加宽就装不下」是**估算**，
   实测表格只有 1574px，1800 本来就够。已改回 1800，护栏保留。
2. **后端 `forward_pe` 已删。** Plan 说「两份实现互相盯住」，但后端那份从不执行，
   而测 Python 证明不了跑着的 TypeScript——是假保证不是双保险。
3. **过期规则改了边界。** Plan 的「早于当年即过期」会在每年 1~4 月误报。

**新引入的风险**

- ⚠️ **一致预期现在有两个来源**：自选股页用东财新表、个股页仍用 akshare 同花顺。
  实测数值几乎一致，但**不是同一个数**；哪天两边差开，用户会问为什么。
- ⚠️ **新鲜度是推出来的，不是上游给的。** `RPT_WEB_RESPREDICT` 没有任何日期字段，
  我用「第一个预测年度」当代理。这个代理的前提是「表停更时年度会落后」——
  如果上游改成滚动年度但不更新 EPS，这个判断会失效。`-m live` 盯着年度不早于当年。
- **表快满了。** 22 列 1574px / 可用 1616px，余量 42px。**下一个想加列的 Goal 会被
  护栏拦住**——那是有意的，届时请先决定砍哪列。
