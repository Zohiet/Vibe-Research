# 一、业务验收（正文）

## 做成了什么

自选股页从 8 列扩到 20 列。以前要判断「今天该点开哪几只细看」，得逐只切到个股数据页去翻
财报和研报，自选二十只就是二十次来回；现在同一屏里就能看到每只的**最新一期财报发布日**
与营收 / 净利同比、ROE，以及**近半年研报**的篇数、覆盖机构、评级分布和**机构目标价区间**。

三件事值得单独说：

**「综合判断」没有由 VR 给出，而是把料配齐后交给用户自己的 AI。** 这是拷打决策 2 的产物。
要权衡的判断——研报密集但都是三个月前的、财报同比转负而评级没跟着下调——写死成公式必然
失真；页面的「让 AI 读自选」现在能拿到全部财报与研报聚合，包括目标价与它的陈旧标注。

**顺带修掉了一个和自选股无关的老问题**：`Layout.tsx` 把**全部 12 个页面**锁在 1152px，
与显示器多大无关。27 寸屏上右侧一千多像素长期闲置。本 Goal 引入了按路由声明的宽屏机制，
目前只有自选股页启用。

**合规口径变更已落到三处**。机构目标价属价格预测，与既有的「不预测涨跌」冲突。负责人明确
拍板要做，因此新口径同时写进 `CLAUDE.md`（给人看）、`chat.SYSTEM_PROMPT`（**运行时真正
生效的那份**）与一条静态护栏（防止被无声删掉）。

## 与 Plan 的偏差

**① 实施步骤 5 的顺序做了调整（已提前告知）。** Plan 要求「宽屏做完先单独验证 `/watchlist` 宽、
`/settings` 窄，再往下做」。实际是先把表格写完，再在 E2E 阶段**把宽屏那条放在文件最前面、
单独先跑一遍**确认通过，然后才生成截图。意图（截图之前必须确认宽屏生效）保住了，
省了一次单独起沙箱的往返。

**② 截图从 5 张减为 4 张。** Plan 里验收项 1 和 2 各配一张图，实跑发现两张**字节数完全相同**
——它们是同一屏上的两组列。截两张一模一样的图不是两条证据，是凑数，合并成一张
`01_财报五列与研报七列.jpg`。

**③ 多改了 `CLAUDE.md` 一行（超出 Plan 授权的范围）。** Plan 只授权改「红线一节 + 前端一节」。
实际还纠正了工具层那句「四个出口同时生效」——核查调用方时发现 `reflection.py` 走
`use_tools=False`、**根本不调工具**，实际是三条。留着一句已被证伪的话比多改一行更糟，
所以改了，在此如实标出。

**④ Plan 没预料到的两处（下次写 Plan 值得记住）：**

- **端点契约里缺了「部分失败怎么办」。** Plan 只写了独立降级（一个端点挂了另一个照常），
  没规定研报端点内部某一只失败时的行为。实现时定为：单只失败跳过（前端显示 `—`），
  **全部失败才 502**——因为源挂了却回 200 + 空数据，界面会渲染成「所有股票近半年都没有
  研报」，那是说谎不是降级。已补测试盯住。
- **单元格需要三态而不是两态。** Plan 的状态流转写了「有值 / 无值」，但 brief 加载中若渲染成
  `—`，会被读成「这只没数据」。实现时加了骨架态。

## 遗留与后续

- **研报端点每只取 `max_pages=1`（上限 100 篇/180 天）**。实测最热的茅台是 32 篇，
  留了三倍余量，但极热门标的理论上会被截断。未做分页，也未在界面上提示截断。
- **巨潮备用路径已实测验证但未实现**（决策 7）。orgId 映射表、category 参数、
  与东财的交叉验证结果都记在设计文档里，真要用时照着写是半天的活。
- **「表格类页宽 / 正文类页窄」的全局分道**仍是待办，本 Goal 只放宽了自选股一页。

# 三、复核要点

**没达成 / 部分达成的验收项**

- 无。14 条全部达成。

**与 Plan 的偏差**

- **多改了 `CLAUDE.md` 一行，超出 Plan 授权范围**：把工具层那句「四个出口同时生效」
  改成「三条」——`reflection.py` 走 `use_tools=False`、不调工具。判断是留着一句已被证伪的
  话更糟，但这确实是 Plan 之外的改动，请你确认这个判断。
- 实施步骤 5 的顺序调整、截图 5 张减为 4 张（两张内容完全相同），细节见正文。
- **Plan 漏了两处，实现时补的**：研报端点「部分失败」的行为（单只跳过 / 全挂才 502）、
  单元格需要三态而非两态。这两条是下次写 Plan 值得带上的模板项。

**新引入的风险**

- ⚠️ **目标价经 `tools.py` 流向 MCP 出口，而 MCP 没有 `SYSTEM_PROMPT` 约束**——提示词由
  对接的宿主（别人的 Claude Desktop 之类）提供，VR 管不到。这是决策 8 你已知情裁决的代价，
  在此再顶一次，因为它是本 Goal 唯一一处「VR 交出去就管不了」的地方。
- **本 Goal 放大了 VR-GOAL-022 剔出的重排风险**：表格从 1100px 增至 1600px、「移除」按钮
  在最右、开着实时行情每 3 秒重排。你裁定删除是极低频动作故不处理，如实留痕。
- **研报每只只取 1 页（≤100 篇/180 天）**，极热门标的理论上会被截断且界面不提示。
  实测最热的茅台 32 篇，余量三倍。
- **`_REPORT_FIELDS` 有个 `≤8` 的字段数上限断言**。将来想给 AI 补更多研报字段时，
  会先撞到这条护栏——那是故意的（守「裁剪后再喂」），但届时要有意识地改而不是顺手放宽。
